# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

**Do not report security vulnerabilities through public GitHub issues.**

Please report vulnerabilities privately using one of these channels:

1. **GitHub Security Advisories (preferred):** [Report a vulnerability](https://github.com/olx-india/go-service-template-clean-architecture/security/advisories/new)
2. **Email:** security@olx.com (include repository name and reproduction steps)

We will acknowledge receipt within 5 business days and provide a timeline for investigation and remediation where applicable.

## Disclosure policy

- We ask that you allow reasonable time for a fix before public disclosure.
- We will coordinate with you on credit for the report if desired.
- Fixed issues will be documented in [CHANGELOG.md](CHANGELOG.md) and released with an appropriate version tag.

## Scope

This policy covers the code and configuration in this repository. Deployments built from this template are the responsibility of adopters.
